## 🗄️ SQL: From Fundamentals to Advanced
This section contains a comprehensive collection of T-SQL scripts and concepts mastered during an intensive 30-hour bootcamp. The scripts range from basic querying to advanced database optimization techniques.

### 💡 Key Concepts Covered:
* **Core SQL:** Data retrieval, advanced filtering, aggregations (`GROUP BY`, `HAVING`), DDL, DML, Complex Joins, and SET Operators.
* **Data Transformation & Cleansing:** String, Numeric, Date/Time manipulation, Handling `NULL` values (`COALESCE`, `ISNULL`, `NULLIF`), and Conditional Logic (`CASE WHEN`).
* **Advanced Aggregations:** Mastering ALL Window Functions (`ROW_NUMBER`, `RANK`, `DENSE_RANK`, `LEAD`, `LAG`, `FIRST_VALUE`, `NTILE` etc.).
* **Complex Logic:** Subqueries, Correlated Subqueries, and Common Table Expressions (Standalone, Nested, and Recursive CTEs).
* **Database Objects:** Creating and managing Views, Temp Tables, and CTAS operations.
* **Automation:** Stored Procedures with Control Flow (`IF/ELSE`), Error Handling (`TRY/CATCH`), and Triggers.
* **Performance Tuning:** Execution Plans, Query Optimization, and Indexing Strategies (Clustered, Non-Clustered, Columnstore, Unique, Filtered).
* **Data Management:** Table Partitions for large datasets.
